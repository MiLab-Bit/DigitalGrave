## **DigitalGrave - 数字墓碑生成器**

**DigitalGrave** 是一个基于 GitHub 数据的数字遗产项目，旨在为每个 GitHub 用户生成一个象征性的“数字墓碑”。通过分析用户的 GitHub 数据（如注册时间、活跃时间、最受欢迎的项目等），为用户创建一个包含个性化“遗言”和“代码遗产”的虚拟墓碑。

它模拟了一个数字化纪念碑的构建过程，其中包含了永恒存档、IPFS 上传模拟等功能。用户可以查看和分享自己的数字墓碑，永久保留自己的 GitHub 代码和贡献历史。

---

### **功能特点**

1. **生前配置 (The Will)**：

   * 输入 GitHub 用户名和自定义的“数字遗言”，为数字墓碑添加个人情感。
   * 允许用户填写想要在墓碑上展示的文字，纪念个人的 GitHub 贡献。

2. **灵魂提取 (Soul Extraction)**：

   * 自动从 GitHub 获取用户信息，包括头像、注册时间和最后活跃时间。
   * 获取 GitHub 的公共数据，分析出用户的代码贡献历史。

3. **墓碑生成 (The Monument)**：

   * 自动生成一个数字墓碑，展示：

     * **生卒年**：从注册时间（First Commit）到最后活跃时间（Last Pulse）。
     * **遗言**：用户填写的最后一段话，表达自己在代码世界中的愿望。
     * **代码遗产**：展示最受欢迎的 GitHub 项目和仓库。
     * **最后的哈希**：模拟用户最后一次提交的 Git 哈希，作为墓志铭。

4. **永恒存档 (IPFS Simulation)**：

   * 模拟将用户的数字墓碑上传至去中心化网络 IPFS，模拟永久存档的过程。
   * 提供“永久封存”功能，让用户的数字遗产永存。

---

### **如何使用**

1. **访问界面**：

   * 直接访问我们的数字墓碑生成器网页：[点击这里访问 DigitalGrave](https://milab-bit.github.io/DigitalGrave/)，即可开始体验。

2. **输入 GitHub 用户名**：

   * 在配置页面中，输入你的 GitHub 用户名。

3. **填写数字遗言**：

   * 在指定文本框中填写你希望在数字墓碑上展示的“数字遗言”。例如：“它曾让某个深夜调试的陌生人感到不再孤单...”

4. **生成数字墓碑**：

   * 点击“生成墓碑”按钮，系统会从 GitHub 拉取相关数据并生成墓碑页面。

5. **IPFS 永久存档**：

   * 用户可以选择将数字墓碑存档到模拟的 IPFS 网络中，确保它可以永存。

---

### **克隆项目安装**

1. 克隆本项目：

   ```bash
   git clone https://github.com/your-username/DigitalGrave.git
   ```

2. 安装依赖：

   ```bash
   cd DigitalGrave
   npm install
   ```

3. 启动开发服务器：

   ```bash
   npm start
   ```

4. 打开浏览器并访问 `http://localhost:3000` 查看应用。

---

### **获取数据**

* **GitHub API**：本项目通过 GitHub API 提供用户数据，包括用户名、注册时间、活跃时间等。
* **数据隐私**：所有数据仅在本地浏览器进行处理，确保用户隐私安全。
